# Trademark and name policy

The SlateCam source code is MIT licensed. That license covers the code, not the
project's identity.

You may:

- Use, modify, and redistribute the code under the terms of the MIT license.
- State that your project is "based on SlateCam" or "a fork of SlateCam".
- Use the name in factual, descriptive references and in academic or
  journalistic writing.

You may not, without permission:

- Ship a modified build under the name "SlateCam" or a confusingly similar name.
- Use the SlateCam icon or wordmark as the identity of a fork.
- Imply that a fork is endorsed by or affiliated with the SlateCam project.

If you publish a fork, give it a distinct name and icon and link back to this
repository. That is enough for almost every use case, and it keeps users from
installing the wrong build.
